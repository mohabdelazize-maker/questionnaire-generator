# 🎓 مولد أسئلة القدرات والتحصيلي

تطبيق ويب متقدم لإنشاء وتحرير أسئلة القدرات والاختبارات التحصيلية بصيغة احترافية مع دعم الصور والرموز الرياضية.

## ✨ المميزات الرئيسية

- 📝 **محرر نصي متقدم** مع دعم الرياضيات والرموز العلمية
- 🖼️ **إدارة الصور** - إضافة وتعديل وترتيب الصور داخل الأسئلة
- 🤖 **توليد ذكي** - إنشاء 5 أسئلة محاكية تلقائياً
- 🔢 **أرقام عربية** - كل الأرقام بالعربية وليس الإنجليزية
- 🎨 **معاينة فورية** - رؤية السؤال بصيغته النهائية فوراً
- 💾 **حفظ واسترجاع** - حفظ الأسئلة محلياً أو على السحابة
- 📊 **تصدير متقدم** - PDF، صور، JSON

## 🛠️ المكدس التقني

### Frontend
- **React 18** - واجهة مستخدم حديثة
- **TypeScript** - كود آمن النوع
- **Tailwind CSS** - تصميم احترافي متجاوب
- **MathQuill** - محرر الصيغ الرياضية
- **React DnD** - سحب وإفلات للصور
- **Zustand** - إدارة الحالة
